	<h1>CaniSat</h1>
	<p>
		We are a community coalition with the mission to advance and provide oversight on <a href="https://en.wikipedia.org/wiki/Digital_audio_radio_service" target="_blank">SDARS</a> technology in the USA and Canada, now and into the future.
	</p>
	<p>
		By hosting open-source resources and software, CaniSat fosters greater choice for subscribers to access crucial information, along with interpreting the service data into standard formats that would otherwise only be managed using proprietary and restrictive software ecosystems.
	</p>
	<p>
		These efforts pick up from previous reverse-engineering done on the <a href="https://en.wikipedia.org/wiki/XM_PCR" target="_blank">PCR and Direct</a> to now also expand towards both new and existing data-supported hardware.
	</p>
